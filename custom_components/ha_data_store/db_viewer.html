🌉 添加远程 HA 连接

连接另一台 Home Assistant 实例。仅需在远程 HA 的「用户资料」中创建长期访问令牌。

📋 添加桥接实体

实体 ID 与远程 HA 保持一致。例如远程 HA 的 switch.fan，桥接后本地也是 switch.fan。

⚡ 操作

添加/删除桥接实体后必须重载，集成重启后实体才会出现

📦 导出 / 导入（备份迁移）

把全部虚拟设备配置 + 当前状态导出为 JSON 文件；换机器/复制数据库后导入，即可自动重建实体并恢复状态。导入跳过正在运行的相同实体（勾选"覆盖"则删除重建）。

🔮 创建虚拟设备

无需重启 HA，即时创建完全功能的虚拟设备。所有实体均使用 RestoreEntity，重启后自动恢复状态。
创建后无需重启 HA，立即可用

📦 导出 / 导入（跨机器迁移）

导出：扫描当前 HA 系统中的原生辅助元素（input_boolean/input_number/input_select/input_text/input_button/counter），连同参数与当前状态生成 JSON 文件。
导入：把该 JSON 导入后转换为本集成自管实体（域前缀变化：input_boolean→switch、input_number/counter→number、input_select→select、input_button→button、input_text→text），无需重启，状态自动回填并在重启后保持。

🆕 新建辅助元素

在 HA 中即时创建一个本集成自管的辅助元素实体（RestoreEntity，重启自动恢复），无需通过原生 HA「辅助元素」再导入。
创建后无需重启 HA，立即可用

⚡ 登记功率实体

登记一个持续上报功率的实体（state 数值为当前功率）。系统每 30 秒采样积分，自动生成三个累计实体（kWh）：sensor.ha_data_store_{id}_daily_ele、..._monthly_ele、..._yearly_ele，并按天存储到数据库。

💬 添加小爱对话实体

配置小爱音箱的对话 sensor 实体（如 sensor.xiaomi_xxx_conversation）。实体状态为用户说的话，answers[0].tts.text 为 AI 回复，timestamp 为对话时间。支持配置多个实体，用 entity_id 区分。

🛠 自定义路由管理

把常用查询固化为独立接口，之后通过 GET /api/ha_data_store/custom/{route_path}?参数=值 直接调用，无需改后端。SQL 必须以 SELECT 开头，推荐用 :name 命名占位符（如 :entity_id），保存后可在 API 地址生成器里自动生成参数输入框；也兼容传统 ? 占位符（此时按参数字母序绑定）。
